# Kinara 1.5.0：Miuix 界面与横屏动态歌词

本版按确认后的 [手机与大屏 HTML 原型](../design/miuix-preview/index.html) 实现原生界面，版本号为 1.5.0 / 17。

## 界面与交互

- 引入官方 Miuix 的主题、Scaffold、导航、卡片、标签、输入框、选择器与开关；音乐、搜索、歌单、下载、设置共用五项导航。
- 宽度达到 900dp 时显示侧导航、内容和当前播放栏，播放按钮保留完整触摸区域。歌曲、专辑、歌手分类使用真实数据。
- 播放页封面下方按标题和收藏、时间线、播放控制、辅助操作重新排布。经典与辉光歌词支持左右滑动；底部入口支持轻点。
- 标准主题提供浅色、深色和简洁、液态玻璃质感。旧版已保存的默认主题迁移为玻璃，新装默认简洁；用户明确选择简洁后不会被迁移覆盖。工业主题保留终末地方向的黄黑、切角与标签排字。
- 滚动区域的实际可见范围避开底部播放条，滚动定位和无障碍操作不会把目标歌曲停在播放条后。设置采用 Miuix 对话框选择器，避免该版本弹出菜单的测量节点重复进入无障碍树。
- 应用明暗与系统明暗不一致时，系统栏图标跟随应用，避免浅色背景上的白色状态栏图标。

## 动态视界

设置中的经典、逐字辉光、动态视界及后者的流光、诗行、绘境、随曲变化均保存到偏好，并接入真实播放页。Folia 的三种渲染器及许可继续保留；产品界面使用 Kinara 标识。

只有主动点击播放页「横屏」才进入横屏视界。横屏隐藏其他播放界面，只保留动态歌词与一条进度控制；轻点画布暂停或继续，松开进度条才提交 seek。返回恢复进入前的封面或歌词模式、方向策略和系统栏。多窗口下保留系统方向策略。

横竖屏使用同一个 WebView 调用点，旋转不会重建渲染页面。离线资源访问边界、画布尺寸检查、失败提示、重试和原生辉光降级均保留。没有可用歌词时使用引擎空歌词行为，不编造歌词或逐字时间。

## 播放与构建

播放继续采用 Media3。时间进度只更新控制条和歌词等必要子树；简洁主题不创建全屏玻璃采样层，也不额外进行背景封面提色。

当前曲目稳定播放 5 秒后，以 5 秒总预算预解析下一首自己的音源；临近结束再次检查短期地址。任务随暂停、切歌取消，不扫描整张队列，不把跨来源录音存到原歌曲缓存键下。既有并发换源、700ms 首播对冲和不可播歌曲继续播放机制保留。新增诊断事件 `RESOLVE_MS`、`NEXT_SOURCE_READY`；它们用于后续实机分析，不代表已测得提速倍数。

工具链使用 JDK 21、Gradle 8.9、AGP 8.7.3、Kotlin / Compose 插件 2.2.10、AndroidX Compose 1.8.3、compileSdk 35。应用 JVM 目标仍为 17，minSdk 24、targetSdk 34。显式采用 R8 8.10.21，满足 Kotlin 2.2 的元数据处理要求，同时保持代码与资源压缩开启。

Miuix 使用官方 `top.yukonga.miuix.kmp:miuix-android:0.5.1`。较新的 0.9.x 依赖需要 API 37；0.5.1 自身类文件为 Java 21，因此构建和 JVM 测试不能继续用 JDK 17。该 AAR 声明 minSdk 26，但其 Android 专有源码仅用 API 23 窗口 Insets，并对 API 31 圆角接口作版本保护。manifest 仅对此库作兼容声明；API 24 的实际组件创建、菜单动作和设置保存有兼容测试。API 24 尚未做实机触摸验收。

Gradle 严格 SHA-256 校验保持开启，新增依赖逐项对照官方 Google Maven / Maven Central。Linux AAPT2 的官方摘要也纳入校验，供公开 CI 使用。纯公开的核验记录见 [依赖验证数据](validation/1.5.0-dependencies.json)。Cloudflare 本地开发工具更新至锁定的 Wrangler 4.161.0，修复其间接 Undici 漏洞；未变更线上 Worker 或凭据。

API 24 的菜单兼容测试使用组件实际无障碍点击动作；API 31/34 测试另行覆盖原生绘制与触摸输入。设备测试中的界面测试歌曲为独立 debug 测试入口的原创数据，不进入 Release。

Windows 跳过项为 `UpdatePolicyTest.fileProviderCannotExposeOtherPrivateFiles`：Android 与 Windows 的绝对路径分隔符不同，现有测试主动跳过。Linux CI 仍执行该测试，没有移除或关闭 FileProvider 的路径保护。公开核验摘要见 [验证数据](validation/1.5.0-summary.json)。

本轮设备为独立模拟实例，不能替代 Android 12 实机的长时间播放、蓝牙、耳机切换、温控或 GPU 帧率验收。没有用模拟器结果推算真机 60fps 或首播提速百分比。上游音源的账号、地区与风控限制仍可能影响播放。
