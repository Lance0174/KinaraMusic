# 1.4.0：歌词动态视界与在线更新

此前只接入 Folia 的 Lumiere，无法选择不同歌词编排引擎。现在设置中的「动态视界」提供三个实际渲染器，以及按录音身份稳定选择的「随曲变化」。旧的 `FOLIA_LUMIERE` 设置值继续兼容，新增视觉样式独立持久化。

| 软件中的名称 | Folia 上游组件 | 实际效果 |
| --- | --- | --- |
| 流光 | Lumiere | 光束、烟雾、粒子、光场中的歌词 |
| 动态排字 | Sonnet | 文字冲击、海报排字、镜头追踪、碎片拼贴 |
| 凝彩 | Tempera | 色块与几何拼贴、文字反色、多种分镜及转场 |

进入「设置 → 歌词与歌曲信息 → 动态视界」选择样式；回到播放页滑到歌词即可体验。减少动效时使用原生静态歌词；渲染失败时明确提示并回退辉光。只有普通 LRC 的歌曲仍按实际行时间显示，不合成逐字时间。此次扩展视觉效果不等于已复现或解决个别歌曲的音源与歌词版本错配。

WebView 继续只加载离线资源。换歌和切换引擎通过串行队列交接，过期初始化被取消，旧画布释放；没有混入在线脚本、React 桌面外壳或外部图片下载。手机画质档位对帧率和纹理设预算，真机流畅度仍需测量。

软件入口仅使用 Kinara 品牌，去除模式与许可按钮上的 Folia 品牌名称。开源许可正文保留上游版权，仓库的 THIRD_PARTY_NOTICES、来源清单及 visualizer/README 明确列出三种引擎、固定上游提交和本地修改。新增上游文件中的 AI 指令性注释已移除并记录，详见供应链复审增量说明。

在线更新位于「设置 → 应用更新」，支持检查正式 Release、阅读说明、下载进度、取消、重试和系统安装。安装包须通过大小、SHA-256、包名、版本名、递增 versionCode 和现有签名核验。没有正式 Release 时显示没有可用更新；不会把未签名 CI 包作为升级。正式发布约定与 fork 配置见 [UPDATES.md](UPDATES.md)。

本地验证：

- Android 共 231 项：230 通过、0 失败、1 项在 Windows 跳过。跳过项为 AndroidX FileProvider 的 Unix 路径边界测试，Linux CI 会执行；其余更新校验与交互测试在本机完成。
- Debug Lint、Release Lint Vital、R8、资源收缩和 Release 构建通过。保留之前的 8 项 Lint 警告，没有新增错误。
- Folia Node 测试 3/3，浏览器/WebGL 6/6。验证三种画面差异、逐字/逐行时间、暂停、seek、低/高画质、空歌词、快速切换、初始化销毁与 WebGL 丢失。
- 已人工检查自动化生成的竖屏模式画面和 Android 设置页截图。不是手机运行截图，也不据此宣称真机帧率。
- 仍需 Android 真机验证系统安装、后台/前台切换及不同 WebView 版本上的视觉与性能。
