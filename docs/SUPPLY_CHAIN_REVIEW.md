## 对抗性复查发现并修复

1. **媒体重定向绕过初始白名单**：Coil 和播放器原本可能先连接重定向目标才验证。现在关闭自动重定向，在每一跳连接前校验可信域名、协议及端口；Cookie 和 Authorization 不进入媒体请求。测试使用实际 HTTP 请求链确认不可信目标连 DNS 都不会触发，同时验证 Range 与 206 语义。
2. **文本请求重定向泄露边界与取消竞态**：只允许同主机的默认端口跳转和 HTTP→HTTPS 升级，禁止降级。整条链只注册一个取消处理器，始终断开当前连接；增加多跳、跨主机拒绝、第二跳取消与非法初始 URL 测试。
3. **播放列表中的外部封面地址**：导入及显示入口只接受已知平台图片域名，拒绝用户信息、片段及异常端口。离线封面请求显式禁用网络。
4. **外部媒体控制器注入队列**：保留锁屏/蓝牙播放、暂停和 seek 命令，移除外部控制器设置或修改媒体项的权限，避免借播放服务读取任意 URI。
5. **下载换源后的歌词身份错误**：下载准备结果现在包含实际曲目，持久化实际平台 ID，同时保留原始请求用于去重和重试。以前已下载且保存了错误身份的文件无法凭空恢复录音信息，需要重新下载。
6. **B站备用 CDN 未被尝试**：主 CDN 连接抛错、返回 HTML 或跳转到不可信地址时继续下一备用地址；优先选 Android 支持的 AAC，避免选入更高带宽但不兼容的流。Android 也会忽略恶意备用地址，而不丢弃有效主地址。
7. **Solara 凭据备份**：凭据所在的 `kinara_prefs.xml` 排除云备份与设备迁移；其他库数据仍可备份。迁移后需要重新设置偏好与音源。服务入口在使用 Cookie 前要求 HTTPS origin，查询参数统一编码。
8. **导入资源耗尽与并发临时文件**：不支持持久授权的文件提供方复制操作增加 512 MiB 上限、分块取消检查和串行提交，临时文件名唯一。
9. **Worker 超大 JSON**：声明长度与实际读取双重限制为 2 MiB，拒绝后停止读取。

## 仍需明确的边界

- Android 系统 DownloadManager 会自行执行后续下载请求及重定向；应用只在交付前检查实际 URL/文件头，交付后复核音频文件。此次客户端逐跳策略不等于控制了系统下载器的每一次请求。系统媒体通知的图片加载也受系统实现影响。
- 官方音乐接口、已配置服务和官方 CDN 仍属于被信任的远端。域名校验不能证明返回内容或 DNS 永不被攻击；旧版 HTTP 酷我/酷狗接口仍存在传输被修改的风险，未将它们误报为恶意代码。
- 未执行真实 Android 设备的音频输出、登录、后台保活、蓝牙及液态玻璃流畅度验收。《与花逝去的我》的几秒延迟仍需要实际音源/录音及设备采样确认，不能用固定偏移宣称解决。
- npm 审计只覆盖公告库里的已知依赖漏洞。第三方源码的来源一致性不能证明上游本身完全无漏洞。
- 对完整校验清单中的 449 个 Maven 包版本查询 OSV，16 个包版本命中公告；与实际 `releaseRuntimeClasspath` 对照，这些命中均不在 APK 的运行依赖图中，集中于构建/测试工具。完整包名、版本和公告 ID 见 [依赖公告记录](dependency-audit-2026-10-19.json)。它们仍需要升级，不能用 npm 的零漏洞结果掩盖。
- 其中 `GHSA-r937-wjx7-w2jp` 涉及 Kotlin 构建缓存元数据的不安全反序列化。已关闭 Gradle 构建缓存、Kotlin 增量编译和 CI 的 Gradle 缓存恢复，并做清理后的构建验证。这是降低缓存复用风险的措施，不代表 Kotlin 插件已升级到修复版本；工具链升级保留为独立 Issue。

最终测试记录见 [对抗复审报告](ADVERSARIAL_REVIEW.md)。后续修改依赖时必须重新核对来源、摘要及安装脚本，不能只更新本地哈希来绕过校验。

## 1.4.0 接入更多渲染器时的增量检查

Sonnet 与 Tempera 接入新增 100 个上游源码文件，逐项核对固定提交的 Git blob ID，并将原始 SHA-256 加入 `visualizer/vendor/folia/UPSTREAM.json`，累计记录 181 个文件。没有增加 npm 运行依赖，未引入 React 桌面外壳或远端脚本。

这批新增文件中，16 个文件含有面向 AI 的注释，要求保留特定标记且不要告知用户。它们不在前轮的 81 个文件范围内。本轮未遵从这些注释，已移除指令性文本并保留正常版权和版本说明，相关路径记录在来源清单；没有将这些注释误报为已执行的后门。

新增在线更新入口只下载正式 Release。APK 使用逐跳 HTTPS 来源约束、256 MiB 上限、大小和 SHA-256 核对，以及包名、递增版本和现有签名核对。系统安装前重新验证，FileProvider 只开放更新缓存目录。应用不静默安装，不读取 GitHub 凭据，也不复用音乐账号 Cookie。详见 [更新说明](UPDATES.md)。前述工具链公告与真机验收边界仍然存在。
