# Kinara · Miuix 双端交互预览

先打开 `index.html`。它并排展示手机和桌面/大屏，可切换主题和页面；选择「横屏视界」查看只保留进度控制的动态歌词画面。

本交付是待确认的 HTML 设计原型，尚未修改正式 Android UI 或接入原生 Miuix 依赖。只有用户确认后，才进入 App 实施和发布阶段。现有签名保持不变，详细范围、依赖兼容性和性能计划见 [DESIGN.md](DESIGN.md)，浏览版见 [proposal.html](proposal.html)。

## 打开方式

推荐使用新版 Chrome 或 Edge。可直接双击 `index.html`；浏览器限制本地文件嵌套页面时，在本文件夹运行：

```text
python serve.py --open
```

然后访问 `http://127.0.0.1:8766/index.html`。服务只监听本机，不发布到互联网。结束时在终端按 Ctrl+C。

## 建议体验顺序

1. 双端查看音乐库；切换浅色、深色、工业外观。
2. 选择搜索，搜索「微光」或「与花逝去的我」；曲目汇总展示，无音源分页。
3. 打开播放页，轻点或左右滑动封面切换歌词，拖动进度，操作队列与喜欢。
4. 设置 → 歌词显示 → 动态视界，或者轻点「体验动态视界」；在播放选项里切换流光、诗行、绘境。
5. 主动进入「横屏」；轻点画面暂停/继续，拖动唯一的进度控制；Esc/浏览器返回退出。

顶部的「横屏视界」是外部审阅工具，可直接比较三种效果。工具栏不属于 App 界面。手机与桌面预览可独立操作；浏览器标签隐藏时暂停动态效果。

## 数据与效果说明

- 普通界面是 HTML/CSS 对 Miuix 设计的模拟，正式实现拟使用官方 Compose 组件。
- 动态视界使用仓库实际打包的 Folia Lumiere/Sonnet/Tempera 渲染代码，不是 CSS 视觉替身。
- 本预览无真实音频，播放按钮驱动演示时钟；不连接音源，不扫描本地音乐，不使用账号、Cookie、API Token 或签名密钥。
- 「Kinara Sessions」曲目、封面及逐字歌词均为原创示例。《与花逝去的我 / 归尘回梦》仅作为用户已提供的搜索示例，不附带其真实音频、封面或歌词。该条目使用占位图并显示无匹配歌词。
- 下载、导入、更新展示交互流程，仅操作示例数据，不下载音乐或发布更新。
- 主题、歌词与渲染选项可保存在浏览器本机的预览设置中，除此之外不持久化账号数据。
- 本机浏览器支持 WebGL 时才可显示动态视界；失败会给出明确提示并可切换歌词样式。
- HTML 流畅不等于 Android 实机流畅，性能实施需依照 DESIGN.md 中的同机对照测量。
