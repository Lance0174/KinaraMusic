# HTML 预览验证

2026-11-12。本报告只覆盖交互原型，不代表 Android 性能测试或正式 App 验收。

## 环境

- Windows / 系统 Chrome，无头浏览器；WebGL 使用 SwiftShader。
- 320 × 740、390 × 844、768 × 900、1200 × 844 四种应用窗口。
- 1680 × 1140 双端审阅页、1100 × 620 横屏动态视界。
- 同时验证本机 HTTP 与直接打开本地 HTML 文件。

## 结果

22 项浏览器检查通过，另完成最终截图与离线审阅工具检查：

- 所有五个导航页面在四种窗口下无横向内容溢出。
- 统一搜索能找到《与花逝去的我 / 归尘回梦》，没有按音源分隔的页面；无结果有明确空状态。
- 示例歌单导入、播放队列删除可操作。
- 轻点与横向滑动封面都能切换到歌词；经典/辉光设置实际改变展示。
- 实际 Folia bundle 初始化完成且 stage/canvas 有非零可见尺寸。
- Lumiere、Sonnet、Tempera 三种导演可分别初始化、切换、显示真实画面。
- 横屏的可见操作控件只有一个进度 range；切换横竖屏保留同一个 renderer iframe，没有重新加载它。
- 轻点画面暂停演示时钟；拖动进度条定位；Esc 和浏览器返回恢复播放页。
- 进入横屏时清除先前的设置提示，避免提示遮住沉浸画面。
- 审阅工具可同步切换手机/桌面页面，并能单独切换横屏视觉风格。
- 本地文件方式可显示实际动态画面，双端审阅工具的页面切换可用。
- 自动化检查中没有脚本异常，也没有外部请求。

原始检查结果随预览 ZIP 附在 `verification.json` 与 `final-capture-check.json`，截图位于 `screenshots/`。
